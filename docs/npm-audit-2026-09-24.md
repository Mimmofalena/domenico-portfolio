## Cosa finisce davvero nel sito (runtime, browser)

Solo **`react-router` / `react-router-dom` 7.9.6** (dipendenza diretta). Advisory principali:
- GHSA-2w69-qvjg-hvjx — XSS via open redirect (≤ 7.11.0)
- GHSA-wrjc-x8rr-h8h6 — open redirect via backslash in `<Link>`/`useNavigate` (< 7.18.0)
- GHSA-chx6-hx7r-mcp5 — DoS su route matching (< 7.18.0)
- Altre relative a SSR / RSC / single-fetch, **non usati** da questo progetto (SPA client-side con `<Routes>`, `<Link>`, `<NavLink>`, `useLocation`).

Rischio reale basso (niente redirect costruiti da input utente), ma va aggiornato: `npm audit fix` porta a **7.18.4**, compatibile con `^7.9.6`.

## Tooling di build/dev (non finisce nel bundle)

Tutto il resto arriva da `react-scripts@5.0.1` (Create React App, non più mantenuto): webpack, webpack-dev-server, jest, eslint, workbox, svgo, postcss, ecc.
Le 2 critical (`shell-quote`, `websocket-driver`) sono dipendenze del dev server.
Il rischio riguarda la macchina di sviluppo/CI (es. dev server esposto in rete), non i visitatori del sito su GitHub Pages.

## Simulazione `npm audit fix` (senza `--force`)

Eseguito su una copia con `--package-lock-only`: da **55 → 23** vulnerabilità (0 critical, 9 high, 5 moderate, 9 low), `react-router` → 7.18.4.

Restano solo dipendenze interne a `react-scripts` (bfj/jsonpath/underscore, serialize-javascript, workbox, webpack-dev-server/sockjs/uuid, yaml 1.x, brace-expansion 1.x, jest 27).
`npm audit fix --force` **non va usato**: proporrebbe `react-scripts@0.0.0`, che rompe il progetto.

## Raccomandazioni

1. **Subito**: `npm audit fix` + `npm run build` + test manuale → elimina critical e react-router.
2. **Opzionale**: aggiungere override mirati in `package.json` (es. `serialize-javascript`, `yaml`, `underscore`) — da verificare con build, possono rompere CRA.
3. **Soluzione definitiva**: migrare da Create React App a **Vite** (CRA è deprecato; la maggior parte delle vulnerabilità residue sparisce con esso).
4. Nota: l'override attuale `"svgo": "^3.0.0"` risolve a una versione vulnerabile (3.0.0–3.3.4); `npm audit fix` la aggiorna.
